# Day 19 Commands

1. `gg / G` — `gg` moves to the first line, while `G` moves to the last line.

2. `:10` — It moves the cursor directly to line 10.

3. `/` — It searches forward for specific text in the file.

4. `?` — It searches backward for specific text in the file.

5. `n / N` — `n` moves to the next search result, while `N` moves to the previous result.

6. `:%s/old/new/g` — This replaces all occurrences of `old` with `new` throughout the file.

7. `dw` — It deletes from the cursor position to the end of the current word.

8. `x` — It deletes the character under the cursor.

9. `o / O` — `o` opens a new line below the current line, while `O` opens one above.

10. `ZZ` — This saves the changes and exits Vim.
