Today, I practiced navigating through files in Vim, searching for specific text, moving between search results, editing individual characters and words, and replacing text throughout a file.

## What surprised me

What I found amazing today was how much can be done in Vim without constantly using the mouse. I can search for text, jump between results, move to specific lines, delete words or characters, and replace text using commands.
