## What I practiced

Today I practiced different ways of reading and inspecting files from the Linux terminal. I worked with commands for reading file contents, viewing specific lines, monitoring updates, counting content, identifying file types, and checking detailed file information.

## What surprised me

I found it surprising that Linux have different commands for reading the same file depending on what information I need, instead of having to open the entire file every time.
