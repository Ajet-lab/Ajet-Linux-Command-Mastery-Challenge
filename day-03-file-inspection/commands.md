# Day 03 Commands

1. `cat file_name` — Displays the contents of a file directly in the terminal. I would use it for quickly viewing small files.

2. `less file_name` — Opens a file in a scrollable view, making it easier to read large files without printing everything at once.

3. `head file_name` — Displays the first 10 lines of a file by default.

4. `head -n number file_name` — Displays a specific number of lines from the beginning of a file.

5. `tail file_name` — Displays the last 10 lines of a file by default.

6. `tail -f file_name` — Continuously displays new lines added to a file, which is useful for monitoring logs in real time.

7. `wc file_name` — Shows the number of lines, words, and bytes in a file.

8. `wc -l file_name` — Shows only the number of lines in a file.

9. `file file_name` — Identifies the type of a file based on its contents.

10. `stat file_name` — Displays detailed information about a file, including its size, permissions, and timestamps.
