# Day 03 Commands

1. `cat file_name` — Displays the contents of a file directly in the terminal. I can use it for viewing small files quickly.

2. `less file_name` — This opens a file page by page, making it easier to read large files without printing everything at once.

3. `head file_name` — It displays the first 10 lines of a file by default.

4. `head -n number file_name` — It shows a specific number of lines from the beginning of a file.

5. `tail file_name` — Displays the last 10 lines of a file by default.

6. `tail -f file_name` — It continuously displays new lines added to a file, which is useful for monitoring logs in real time.

7. `wc file_name` — This shows the number of lines, words, and bytes in a file.

8. `wc -l file_name` — Shows only the number of lines in a file.

9. `file file_name` — Identifies the type of a file based on its contents.

10. `stat file_name` — It displays detailed information about a file, including its size, permissions, and timestamps.
