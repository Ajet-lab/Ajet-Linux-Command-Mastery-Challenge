## What I practiced

Today I practiced managing software packages on Debian/Ubuntu systems using APT. I updated package information, upgraded installed packages, installed and removed software, searched for packages, and inspected package details. I also explored `dpkg` for checking installed packages and viewing the files provided by a package.

## What surprised me

What surprised me was that updating the package list and upgrading installed software are two different tasks. `apt update` refreshes information about available packages, while commands like `apt upgrade` actually install available updates.
