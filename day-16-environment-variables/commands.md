# Day 16 Commands

1. `printenv` — It displays the environment variables currently available in the shell environment.

2. `printenv HOME` — It displays the value of the `HOME` environment variable.

3. `echo $VAR` — It displays the value stored in an environment or shell variable named `VAR`.

4. `export VAR=value` — It creates or exports a variable so it becomes available to programs started from the current shell.

5. `unset VAR` — It removes a shell or environment variable from the current shell session.

6. `env` — This displays the current environment and can also be used to run a command with a modified environment.

7. `source filename` — It reads and executes commands from a file in the current shell, commonly used to reload shell configuration changes.

8. `echo $PATH` — This displays the directories Linux searches when you type a command without its full path.

9. `export PATH=$PATH:/new/directory` — It adds another directory to the existing `PATH` for the current shell session.

10. `cat /etc/environment` — This displays system-wide environment variable settings defined in `/etc/environment`.
