## What I practiced

Today I practiced viewing and managing environment variables. I explored how to display variables, create and export variables, remove them, reload configuration files, and understand how the `PATH` variable affects where Linux looks for executable commands.

## What surprised me

What I found interesting and suprising in today's command was how `source` command works, how amazing you can create a script file - here I noticed the file has to end in **.sh** , you then create your variables in the file, as much as you can. After saving up that's when you `source` the file, which makes it available to be echoed or displayed. Also If you wrongly set a path, some basic commands like `ls` `cat` `sudo` wonuld not be recognized but then this is just temporary, if terminal is closed and relauched, everything works fine.
