# Day 08 Commands

1. `sudo command` — It runs a command with elevated privileges when my user is allowed to use `sudo`.

2. `sudo -i` — This opens an interactive root login shell, giving me a root environment.

3. `sudo -u user command` — It runs a command as a specified user instead of my current user.

4. `sudo !!` — Re-runs my previous command with `sudo` added to it.

5. `sudo -l` — It shows the commands the current user is allowed to run with `sudo`.

6. `visudo` — Safely opens the sudoers configuration file for editing and checks its syntax before saving.

7. `su` — It switches to another user account, usually asking for that user's password.

8. `su -` — This switches to another user and starts a login shell with that user's environment.

9. `whoami` — This shows the username of the account currently being used.

10. `id` — This shows my user ID, group ID, and the groups associated with my account.
