# Day 02 Commands

1. `mkdir directory_name` — Creates a new directory.

2. `mkdir -p path/to/directory` — Creates a directory along with any missing parent directories in the path.

3. `touch file_name` — Creates an empty file.

4. `cp source destination` — Copies a file from one location to another.

5. `cp -r source destination` — Copies a directory and everything inside it.

6. `mv source destination` — Moves a file or directory. It can also be used to rename one.

7. `rm file_name` — Deletes a file.

8. `rm -r directory_name` — Deletes a directory and its contents recursively.

9. `rm -rf directory_name` — Forcefully deletes a directory and its contents without asking for confirmation.

10. `rmdir directory_name` — Deletes an empty directory.
