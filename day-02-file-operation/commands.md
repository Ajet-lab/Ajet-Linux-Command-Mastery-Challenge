# Day 02 Commands

1. `mkdir` — For creating a new directory.

2. `mkdir -p` — This creates nested directories i.e multiple directory at a time e.g path/to/directory.

3. `touch` — Creates an empty file, you add the file name after `touch`.

4. `cp source destination` — It Copies a file from one location to another.

5. `cp -r source destination` — for Copying a directory and everything inside it.

6. `mv source destination` — Moves a file or directory. It can also be used to rename one.

7. `rm` — It deletes a file, you add the file name after `rm`.

8. `rm -r directory_name` — It deletes a directory and its contents recursively.

9. `rm -rf directory_name` — This forcefully deletes a directory and its contents without asking for confirmation, be extremely careful when using this

10. `rmdir directory_name` — Deletes an empty directory.
