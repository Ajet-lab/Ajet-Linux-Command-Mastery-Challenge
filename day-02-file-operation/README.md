## What I practiced

Today I practiced creating, copying, moving, renaming, and deleting files and directories. The drill involved creating a nested folder structure, adding empty files, copying the folder to a backup location, renaming a file, and removing empty directories safely.

## What surprised me

I discovered that I can only use "mv" to move files that exist in the current directory or sub-directory that you're currently.
