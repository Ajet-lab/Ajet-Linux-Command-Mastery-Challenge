## What I practiced

Today I practiced changing file ownership and groups using `chown` and `chgrp`, as well as working with special permissions such as SUID, SGID, and the sticky bit. I also practiced finding SUID files and managing additional permissions with ACLs.

## What surprised me

What surprised me was how special permission bits can change the way a file or directory behaves, giving Linux more control over access than basic read, write, and execute permissions alone.
