# Day 20 Commands

1. `grep` — It searches for a specific word or pattern in text.

2. `grep -r` — It searches for a word or pattern inside files and directories recursively.

3. `grep -i` — It searches without considering uppercase or lowercase letters.

4. `sort` — It sorts lines of text alphabetically.

5. `sort -n` — It sorts numbers according to their numerical value.

6. `uniq` — This removes consecutive duplicate lines from sorted text.

7. `cut -d',' -f` — This uses a comma as the delimiter and extracts a specific field from each line.

8. `awk '{print $1}'` — This extracts and prints the first field from each line.

9. `sed 's/old/new/g'` — This replaces all occurrences of `old` with `new` in each line.

10. `|` — It connects commands so the output of one command becomes the input of another.
