# Day 28 Commands — Bash Scripting Foundations

1. `#!/bin/bash` — Shebang that tells the system to use Bash to interpret the script.
2. `chmod +x script.sh` — This gives the script permission to be executed.
3. `./script.sh` — It runs an executable script from the current directory.
4. `VAR=value` — It creates a variable and assigns a value to it.
5. `$(command)` — It runs a command and uses its output inside another command.
6. `read -p` — this displays a prompt and stores the user's input in a variable.
7. `if / elif / else / fi` — They allow a script to make decisions based on conditions.
8. `-gt / -lt / -eq` — They compare numerical values as greater than, less than, or equal to.
9. `for` loop — It repeats a set of commands for each item in a list or range.
10. `while` loop — It repeats a set of commands while a condition remains true.
