## What I practiced

Today I practiced the basic Linux commands used to navigate and understand the filesystem. I learned how to check my current location with `pwd`, list files and directories using different `ls` options, and move between directories using `cd`.

I practiced moving to a directory using an absolute path, moving one level backward with `cd ..`, returning to my home directory with `cd ~`, and switching back to my previous directory with `cd -`.

The main goal was to become comfortable moving around the Linux filesystem from the terminal without relying on a graphical file manager.
