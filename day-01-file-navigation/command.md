Command	Meaning
pwd     Show your current directory
ls	    List files and directories in your current directory
ls -l	List files and directories with detailed information
ls -a	Show you all files, including hidden files 
ls -la	Show you all files and directory with detailed information
ls -lh	list in detailed with human-readable sizes (eg M K G )instead of raw bytes
cd (absolute path)	Move using a complete/absolute path
cd ..	Go up to the parent directory 
cd ~	Go to home directory from your current directory
cd -	Go back to your previous directory
