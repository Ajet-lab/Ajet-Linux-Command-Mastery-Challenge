**Day01 Commands**
pwd   Show your current directory
ls	  List files and directories in your current directory
ls -l	List files and directories with detailed information
ls -a	Show you all files, including hidden files 
ls -la	Show you all files and directory with detailed information
ls -lh	list in detailed with human-readable sizes (eg M K G )instead of raw bytes
cd (absolute path)	Move using a complete/absolute path
cd ..	Go up to the parent directory 
cd ~	Go to home directory from your current directory
cd -	Go back to your previous directory


pwd — Shows the full path of the directory I am currently in.
ls — Lists the files and directories in the current location.
ls -l — Shows files and directories in a detailed format, including permissions and ownership.
ls -a — Shows all files, including hidden files.
ls -la — Shows all files, including hidden files, with detailed information.
ls -lh — Lists files with detailed information and displays file sizes in a human-readable format.
cd /absolute/path — Moves me directly to a directory using its full path.
cd .. — Moves me one directory level up.
cd ~ — Takes me to my home directory.
cd - — Takes me back to the previous directory I was working in.
