## Phase 3 - Users, Groups & Package Management | Day 11 of 30

## Commands covered today

See [commands.md](./commands.md) for all 10 commands with their correct syntax and my own explanation of what each one does and when I would use it.

## What I practiced

Today I practiced creating user accounts with different options, setting passwords, modifying existing accounts, adding users to groups, changing login shells, renaming users, and removing user accounts when they are no longer needed.

## What surprised me

What I found interesting, which doesn't seems to amaze me, is how Linux provides different ways/commands to solve a problem. You just need to keep practising and get used to new commands that can be easily remember. For example the use of `useradd` and `adduser` they the same objective of creating a new user just that one ask for more information while creating the user.
