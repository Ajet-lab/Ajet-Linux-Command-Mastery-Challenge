# Day 30 Commands — Checkpoint Capstone: Full System Command Mastery Review

1. `ps + systemctl + journalctl` — This combines process, service, and log information into one system health report.
2. `ssh <user>@<host> "<command>"` — This connects to a remote Linux host and runs a command remotely.
3. `scp <source> <destination>` — This securely transfers a file between local and remote systems.
4. `chmod` — It applies the required permissions to files and directories.
5. `chown` — It changes the ownership of deployed files and directories.
6. `crontab` — It cchedules the system health-check script to run automatically.
7. `grep / awk / sed` — Filters, extracts, and transforms information from logs and command output.
8. `find` — It locates stale or unwanted files that can be identified for cleanup.
9. `last / who / history` — It reviews login activity, current users, and command history as part of a basic security audit.
10. `300-command journal` — It reviews and presents the commands practiced throughout the 30-day challenge.
