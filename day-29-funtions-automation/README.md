## What I practiced

Today I practiced making Bash scripts more reusable and automated by working with functions, positional arguments, exit codes, cron scheduling, background execution, traps, and system logging.


## What surprised me

What surprised me was how a Bash script can be made much more flexible by using functions and arguments. Instead of writing a separate script for every task, one script can accept different inputs and perform the required operation.
I also found it interesting how cron can be used to schedule scripts automatically without needing to run them manually every time.
