# Day 29 Commands — Functions, Arguments & Automation

1. `function_name() { }` — It defines a reusable Bash function that can contain a set of commands.
2. `$1 / $2` — This represents the first and second positional arguments passed to a script or function.
3. `$# / $* / $@` — This shows the number of arguments and accesses the arguments passed to a script or function.
4. `$0` — It represents the name of the script or shell being executed.
5. `$?` — It shows the exit status of the most recently executed command.
6. `crontab` syntax — This defines when and how scheduled commands or scripts should run.
7. `0 * * * *` — This cron schedule that runs a task at the beginning of every hour.
8. `nohup script.sh &` — This runs a script in the background so it can continue running after the terminal session ends.
9. `trap` — It allows a script to respond to signals or specific events.
10. `logger` — It ends messages from a script or command to the system log.
