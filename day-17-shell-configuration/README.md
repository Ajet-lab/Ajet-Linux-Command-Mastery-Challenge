## What I practiced

Today I practiced making environment settings and shell customizations persist across terminal sessions. I explored shell configuration files, created and managed aliases, reloaded `.bashrc` without opening a new terminal, and used commands to identify where other commands are located.

## What surprised me

What I found interesting in today's practice was the use of `alias`. It makes more sense to me as you can always use short words to represent a command and also a short Phrase joined together in order to remember the use of a paticular command. But then we need to be careful while using `alias`, because when we get used to it we might ended up losing the ability to know commands to use quickly for executing basic operations. But then its easier to become comfortable with it if it's temporarily used.
