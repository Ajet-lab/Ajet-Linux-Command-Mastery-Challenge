## What I practiced

Today I practiced connecting to remote Linux machines using SSH, authenticating with SSH keys, transferring files between systems, and configuring SSH connections. I also learned about SSH server configuration and basic hardening.

## What surprised me

What surprised me was how SSH can do much more than simply connect to another machine. The same system can be used to securely access remote servers, transfer files, synchronize directories, and configure easier and more secure connections.
