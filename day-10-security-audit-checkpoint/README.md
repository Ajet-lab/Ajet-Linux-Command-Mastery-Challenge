## What I practiced

Today was a security checkpoint for Phase 2. I practiced auditing SUID files, checking user and login activity, reviewing login history, checking group membership, inspecting password and account aging information, and reviewing commands previously run with `sudo`.

## What surprised me

What surprised me was how much information Linux keeps about users, logins, and system activity. Different commands can reveal different parts of the system's security history, making them useful when auditing or investigating activity. Also how significant a letter can be a command like `w` it looks just like a random letter but it's a command on its own that's important to know.
