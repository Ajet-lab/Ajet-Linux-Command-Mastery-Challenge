## What I practiced

Today I practiced using `systemctl` to start, stop, restart, reload, enable, and check the status of system services. I also learned the difference between a service being active and being enabled to start automatically.

## What surprised me

What surprised me was that starting a service `systemctl start` and enabling a service `systemctl enable` are not the same thing. A service can be running now without being configured to start automatically after a reboot.
