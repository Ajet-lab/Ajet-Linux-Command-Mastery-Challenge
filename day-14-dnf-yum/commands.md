# Day 14 Commands

1. `sudo dnf update` — This updates installed packages and refreshes package information on DNF-based Linux distributions such as Fedora and newer RHEL-based systems.

2. `sudo dnf install package_name` — It installs a specified software package using the DNF package manager.

3. `sudo dnf remove package_name` — It removes an installed package from a DNF-based system.

4. `dnf search keyword` — It searches available repositories for packages matching a keyword.

5. `sudo yum install package_name` — It installs a package using YUM, commonly associated with older RHEL/CentOS-based systems.

6. `rpm -qa` — This lists packages known to the RPM package database.

7. `sudo snap install package_name` — It installs software using the Snap package management system.

8. `sudo add-apt-repository repository` — This adds a new APT software repository so packages from that source can become available to the system.

9. `sudo dpkg -i package.deb` — It installs a local `.deb` package file directly.

10. `pip install package_name` / `npm install package_name` — It installs Python packages with `pip` or JavaScript/Node.js packages with `npm`.
