## What I practiced

Today I explored package management beyond APT. I practiced commands used on RPM-based Linux distributions, such as `dnf`, `yum`, and `rpm`, and also looked at alternative installation methods including Snap, manually installing `.deb` packages, adding repositories, and installing packages through language-specific tools like `pip` and `npm`.

## What surprised me

What surprised me was that installing software on Linux does not always follow one method. The command and package manager depend on the Linux distribution and the type of software being installed.
