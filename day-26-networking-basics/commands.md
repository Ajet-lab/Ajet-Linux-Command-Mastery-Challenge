# Day 26 Commands — Networking Basics

1. `ip a` — This displays network interfaces and their IP addresses.
2. `ip route` — This displays the system's routing table.
3. `ping -c <count> <host>` — It tests network connectivity by sending a specified number of packets.
4. `curl <URL>` — it makes a request to a URL and displays the response.
5. `curl -I <URL>` — It retrieves the HTTP headers from a URL without downloading the full content.
6. `wget <URL>` — It downloads files or resources from a URL.
7. `netstat -tulnp` — This displays listening TCP/UDP ports and the processes using them.
8. `ss -tulnp` — This displays listening sockets and associated processes.
9. `hostname` — This displays the system's hostname.
10. `hostnamectl` — This displays and manages hostname-related system information.
