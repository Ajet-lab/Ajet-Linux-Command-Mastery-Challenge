# Day 18 Commands

1. `vim <file>` — It opens a file in Vim for editing. If the file does not exist, Vim can create it when the changes are saved.

2. `i` — It enters insert mode, allowing me to type and edit text.

3. `Esc` — It leaves insert mode and returns to Vim's command mode.

4. `:w` — It saves the current changes without closing Vim.

5. `:q` — This quits Vim when there are no unsaved changes.

6. `:wq` / `:x` — This saves the changes and exits Vim.

7. `:q!` — This exits Vim without saving the changes made since the last save.

8. `dd` — It deletes the current line.

9. `yy` / `p` — `yy` copies the current line, while `p` pastes the copied line below the current line.

10. `u` / `Ctrl+r` — `u` undoes the last change, while `Ctrl+r` redoes a change that was undone.
