# Day 21 Commands

1. `ps aux` — It shows detailed information about all running processes.

2. `ps -ef` — It displays running processes in a full-format listing.

3. `ps -u` — It shows processes belonging to a specific user.

4. `top` — This displays running processes and system resource usage in real time.

5. `htop` — This provides an interactive and easier-to-read view of running processes.

6. `pgrep` — It finds the PID of a process by its name.

7. `pstree` — It shows running processes in a tree structure, displaying parent and child relationships.

8. `lsof -i` — It shows processes using network connections.

9. `jobs` — This lists jobs running in the current shell, including background jobs.

10. `nice / renice` — `nice` starts a process with a chosen priority, while `renice` changes the priority of an existing process.
